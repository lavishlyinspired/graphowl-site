from graphowl import GraphOWL

owl = GraphOWL(url=URL, api_key=TOKEN)
rows = owl.query.sparql("""
  SELECT ?class (COUNT(?s) AS ?n)
  WHERE { GRAPH ?g { ?s a ?class } }
  GROUP BY ?class ORDER BY DESC(?n)""")
const res = await fetch(`${URL}/sparql`, {
  method: "POST",
  headers: { Authorization: `Bearer ${TOKEN}`,
             "Content-Type": "application/json" },
  body: JSON.stringify({ query: `SELECT ?class (COUNT(?s) AS ?n)
    WHERE { GRAPH ?g { ?s a ?class } }
    GROUP BY ?class ORDER BY DESC(?n)` }),
});
const { rows } = await res.json();

What you get

Not a metadata catalog with a graph bolted on: the engine does the work.

Every fact keeps its history

Nothing is deleted, only retracted. Ask any question as it stood at an earlier moment.

Reasoning you can tell apart

OWL 2 RL derives what follows from the model, and marks it as derived so it is never mistaken for stated.

Review before effect

Models proposed by software are proposals until a person approves them. Nothing changes the graph unreviewed.

SPARQL and Cypher

Two ways to ask the same graph. SPARQL 1.1 and a documented Cypher subset, with honest errors.

Validation built in

SHACL-style constraints and quality expectations report what does not fit, without changing it.

Packs for any domain

Ontology, glossary, rules and expectations bundled per domain, so one engine serves many.

Virtual graphs

Query a source database in place, through a mapping a reviewer approved.

People and agents, one engine

A console, an HTTP API, client libraries and an MCP server, all on the same facts.

Built in Rust

The server is written in Rust, as a workspace of small, single-purpose crates.

Safe and steady

Memory safety without a garbage collector: whole classes of crashes and security flaws cannot be written in safe code, and there are no collector pauses to show up as latency spikes.

One server to run

The server, the API and the console ship as one program. No runtime or virtual machine to install, and few moving parts to operate.

Rules in the types

A fact has a source, a derived fact is marked derived, a model change needs review. These are encoded in types, so breaking them is a compile error.

What is open, and what is not

Public

  • Documentation and the full API description
  • Client libraries (Python and TypeScript, Apache-2.0)
  • Runnable examples and sample data
  • Standards conformance, dated
  • Software bill of materials and licences
  • Issues, discussions and a security policy

Not public

  • The server's source code: it is proprietary
  • Production use is not covered by the evaluation licence

GraphOWL is in early access: the API may change before 1.0, and known limits are listed plainly.
